# Fueldezign CRM Frontend

React dashboard for the private Fueldezign CRM workspace.

## Setup

```bash
cd Frontend
npm install
cp .env.example .env
npm run dev
```

Open `http://localhost:5173` and log in with the Django superuser or any user created in Django admin.

## Stack

- Vite, React, TypeScript
- Tailwind CSS with shadcn/ui-style primitives
- TanStack Query and TanStack Table
- React Hook Form and Zod
- React Router
